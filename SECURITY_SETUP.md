# Security Setup Guide

This guide explains how to use the security setup script to generate secure credentials for your Risk Factor Comparison App.

## What the Security Setup Script Does

The `security_setup.py` script:
- Generates a cryptographically secure `FLASK_SECRET_KEY` using Python's `secrets` module
- Manages your `.env` file with sensitive configuration
- Provides both interactive and non-interactive setup modes
- Prevents accidental exposure of secrets (masked in output)

## Prerequisites

1. Ensure `python-dotenv` is installed:
   ```bash
   pip install -r requirements.txt
   ```

2. Verify `.env` is in your `.gitignore` (it should be) ✓

## Usage

### Interactive Setup (Recommended)

For the first-time setup, run the interactive wizard:

```bash
python security_setup.py
```

This will prompt you for:
1. **Flask SECRET_KEY**: Auto-generated securely
2. **Database URL**: PostgreSQL connection string (can be skipped)
3. **Flask Environment**: Choose between development, production, or testing

### Non-Interactive Setup

For automated deployments or CI/CD:

```bash
# Generate with defaults (production environment)
python security_setup.py --non-interactive

# Specify environment and database
python security_setup.py --non-interactive --flask-env production --db-url "postgresql://user:pass@localhost/dbname"
```

### Regenerate Secrets

If you need to regenerate all secrets (e.g., if previous keys were compromised):

```bash
python security_setup.py --regenerate
```

## Integrating with Your Flask App

Add this to the top of `web_app.py` (after imports, before Flask app creation):

```python
from dotenv import load_dotenv

# Load environment variables from .env file
load_dotenv()

# Now create your Flask app
app = Flask(__name__)

# Load configuration from environment
app.config['SECRET_KEY'] = os.getenv('FLASK_SECRET_KEY', 'dev-key-change-in-production')
app.config['SQLALCHEMY_DATABASE_URI'] = os.getenv('DATABASE_URL', 'sqlite:///app.db')
app.config['ENV'] = os.getenv('FLASK_ENV', 'production')
```

Example integration (add after line 15 in web_app.py):

```python
from dotenv import load_dotenv

load_dotenv()
``` 

Then update your Flask initialization:

```python
app = Flask(__name__)
app.config['SECRET_KEY'] = os.getenv('FLASK_SECRET_KEY', 'fallback-key-for-testing')
```

## File Descriptions

- **`security_setup.py`**: Main setup script - run this once to initialize security
- **`.env`**: Your secret configuration file (auto-generated, never commit this)
- **`.env.example`**: Template showing what goes in `.env` (safe to commit)
- **`.gitignore`**: Already configured to prevent `.env` from being committed

## Security Best Practices

✓ **Always:**
- Run `security_setup.py` before deploying to production
- Keep `.env` out of version control (it's in `.gitignore`)
- Use strong, unique keys generated by this script
- Review generated values in `.env.example` before committing
- Use different `FLASK_ENV` values for dev vs. production
- Add additional sensitive config to `.env` as needed

✗ **Never:**
- Commit `.env` file to git
- Share the contents of `.env`
- Hardcode secrets in your Python files
- Use the same secret key across environments
- Share screenshots or logs that might expose `.env` contents

## Troubleshooting

### Script doesn't run
- Ensure you're in the project root directory
- Check Python version: `python --version` (3.7+)
- Install requirements: `pip install -r requirements.txt`

### `.env` file not being created
- Check write permissions in the project directory
- Ensure the path doesn't contain characters that could cause issues
- Run with admin privileges if necessary

### Flask app not reading `.env`
- Verify `.env` file exists in the project root
- Check that `load_dotenv()` is called before accessing environment variables
- Restart your Flask development server after creating/modifying `.env`

## Advanced Usage

### Using the SecuritySetup class in other scripts

```python
from security_setup import SecuritySetup

setup = SecuritySetup()
setup.setup_flask_secret_key()
setup.setup_flask_env('production')
setup.display_summary()
setup.save_env_file()
```

### Generating additional API keys

```python
from security_setup import SecuritySetup

setup = SecuritySetup()
api_key = setup.generate_api_key(prefix="sk_", length=32)
```
